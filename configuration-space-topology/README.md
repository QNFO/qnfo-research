# Configuration-Space Topology and the Distinction Calculus

**WBS:** QNFO.RES.011 — **Branch:** `res/paper/configuration-space-topology` — **Repo:** QNFO/qnfo-research

Configuration-space topology (CST) derives exchange statistics from the
topology of the configuration space of indistinguishable particles:
π₁(C_N(M)) = S_N (bosons/fermions, d ≥ 3) and π₁(C_N(M)) = B_N (anyons, d = 2).

This project investigates whether CST is the terminus or a map with known
limits, and whether the Distinction Calculus — lifted into Homotopy Type
Theory, with the Grothendieck–Teichmüller group acting on braided monoidal
categories — supplies the origin of the space in which the configurations
live.

with falsification conditions F1-F3.
