# Detailed 2‑Day LLM‑Orchestrated Sprint Plan

## Overview

**Goal:** Execute immediate, low‑risk actions from the research plan to produce:
1. Statistical assessment of near‑matches (p‑value).
2. Extended computational scan (≥100 length scales, all massive fermion mass ratios).
3. Short preprint note consolidating the geometric reframing.
4. Public code repository.

**Team:** Human orchestrator + 4 simulated LLM agents (`CodeAgent`, `SearchAgent`, `WriteAgent`, `VerifyAgent`).  
**Tools:** Python environment, arXiv API, GitHub/Gist, Markdown editor, shared folder (e.g., Google Drive or local directory with version control).

**Guiding principle:** Human makes all final decisions; agents propose, execute, and validate.

## Day 1 – Morning (4 hours): Monte Carlo & Near‑Match Assessment

### 08:00 – 08:30 | Human setup
- Create `sprint_log.md` with headers for each session.
- Post task to `CodeAgent`: “Write script `monte_carlo_near_matches.py` that implements the following specification.”

**Specification for CodeAgent (to be copied into prompt):**
```python
"""
Input: targets.json (contains yukawa_values and weak_ratio), tolerances list [0.0093, 0.0082, 0.0089, 0.0089].
Define n_ratios = 600, n_targets = 4 (ye, ymu, ytau, mW/mZ).
Log range: from ln(1e-6) to ln(1e22) (approx -13.8 to 50.7).
Null hypothesis: ratios are uniformly distributed in log space.
For each trial (1 million):
  - Generate n_ratios random log-uniform numbers.
  - Convert to linear ratios.
  - For each target, count how many ratios fall within relative tolerance.
  - Sum counts across targets.
Compute p-value = fraction of trials where total matches >= 5 (the observed number).
Output: p-value, histogram of match counts, cumulative distribution plot.
Save results as outputs/mc_results.json and outputs/mc_histogram.png.
"""
```

- Human posts the specification to `CodeAgent`. Agent writes script and saves to `code/monte_carlo_near_matches.py`.

### 08:30 – 09:30 | CodeAgent execution
- Agent runs script (should take ~5‑10 minutes for 1M trials). Captures output.
- If errors, agent debugs and re‑runs.
- Produces `outputs/mc_results.json` (with p‑value, mean matches, standard deviation) and `outputs/mc_histogram.png`.

### 09:30 – 10:00 | VerifyAgent check
- Human: “`VerifyAgent`, check the Monte Carlo script for logical errors: (a) Are tolerances applied correctly as relative? (b) Is the log‑uniform generation correct? (c) Is the p‑value computed as proportion of trials with matches ≥5?”
- Agent returns pass/fail with comments. Human reviews.

### 10:00 – 10:30 | WriteAgent drafting
- Human: “`WriteAgent`, draft a subsection titled ‘Statistical assessment of near‑matches’ to be inserted into §6 of the main document. Use the p‑value from mc_results.json. Include the histogram as Figure X. Conclude that the near‑matches are not statistically significant (p > 0.05). Keep tone neutral.”
- Agent produces `drafts/near_match_stats.md`.

### 10:30 – 11:00 | Human integration
- Human edits the draft for clarity, ensures no overstatement, then inserts into `Quantum-Mechanical Physics as Invariant Geometric Structure.md` (as new subsection 6.5). Saves as `final/updated_main_v1.md`.
- Human commits change to local git.

**Deliverable after morning:** Updated main document with statistical caveat.

## Day 1 – Afternoon (4 hours): Extended Scale Library & Scan Script

### 11:00 – 12:00 | SearchAgent – build scale library
- Human: “`SearchAgent`, compile a list of physical length scales from these categories:
  1. Electromagnetic: classical radii and reduced Compton wavelengths for e, μ, τ; Bohr radius; Rydberg wavelength.
  2. QCD/hadronic: Sommer scale r0 (0.47 fm), string tension scale (0.42 GeV → length = ħc / 0.42GeV), proton charge radius (0.84 fm), neutron charge radius (−0.11 fm^2 root‑mean‑square, but use magnitude), nucleon magnetic radius (0.85 fm), axial radius (0.67 fm), pion decay constant scale (ħc / (92.3 MeV)), reduced Compton wavelengths for π, ρ, Δ, Ω baryon, Λ baryon, Σ baryon, Ξ baryon, D meson, B meson.
  3. Electroweak: reduced Compton wavelengths for W, Z, H, top quark, and also 1/(Higgs VEV) as a length.
  4. Gravitational: Planck length, electron Schwarzschild radius, proton Schwarzschild radius.
  5. Cosmological: Hubble length (~1.4e26 m) for completeness (Type III).
  Output a JSON file `data/scales.json` with each entry: {“name”: “r_e”, “value_m”: 2.81794e-15, “source”: “CODATA 2018”}. Include uncertainty if available.”
- Agent queries known sources (PDG Live, CODATA, lattice reviews) and produces JSON.

### 12:00 – 12:30 | Human review
- Human checks a few entries against memory (e.g., r0 = 0.47 fm, fπ = 92.3 MeV → L_fπ = 197.3/92.3 ≈ 2.14 fm). Approves or requests corrections.

### 12:30 – 13:30 | CodeAgent – extended scan script
- Human: “`CodeAgent`, write `code/extended_scan.py` that:
  - Reads `data/scales.json`.
  - Computes all pairwise ratios (A/B and B/A) for N scales → ~N*(N-1) ratios.
  - For each target mass ratio (mp/me, mmu/me, mtau/me, mt/me, mb/me, mc/me) and for each Yukawa (ye, ymu, ytau) and for mW/mZ, find the ratio that minimizes relative error.
  - Store results in a pandas DataFrame with columns: target, best_ratio_value, best_ratio_name (e.g., “lambda_top / lambda_e”), relative_error, is_tautological (boolean: true if the ratio is Compton ratio of two particles or classical radius ratio of two leptons).
  - Output `outputs/extended_scan_results.csv` and `outputs/extended_scan_summary.json` (containing for each target the minimum relative error among non‑tautological ratios).
  - Also compute expected chance matches using bootstrap: randomly pair scales from the set, compute ratio, record number of times it falls within 1% of each target. Do 100,000 bootstraps and store empirical p‑value for each target.”
- Agent writes script, includes necessary imports.

### 13:30 – 14:30 | CodeAgent execution (may run overnight if large)
- Agent runs script. If N≈100, pairwise ratios ~10,000, bootstrap 100k → ~1 billion ratio checks – may take hours. Human decides to run with N=50 first (fast) then expand. For sprint, we aim N≥60 for reasonable coverage.
- Agent logs progress. If time exceeds, human may approve overnight run and move to other tasks.

### 14:30 – 15:00 | VerifyAgent spot‑check
- Human: “`VerifyAgent`, randomly pick 5 ratios from the output (e.g., `lambda_Z/lambda_p`, `r_e/lc_mu`, `lc_p / r0`). Verify that each ratio value matches the manually computed value using input scales. Report any discrepancy > 1e-9 relative.”
- Agent performs checks and reports.

**Deliverable after afternoon:** Extended scan results (assuming completion) plus bootstrap p‑values.
