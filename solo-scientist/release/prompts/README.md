# Prompt Library — The Force-Multiplier Playbook

Five reusable prompt patterns that cover the full research pipeline. Each is standalone — copy, paste, fill in the bracketed fields, and use.

## The Prompts

| # | Prompt | Use When |
|:--|:-------|:---------|
| 1 | [Literature Synthesis](01-literature-synthesis.md) | Bootstrapping a new research area |
| 2 | [Derivation with Reality Check](02-derivation-reality-check.md) | Deriving equations with built-in verification |
| 3 | [Code Prototyping](03-code-prototyping.md) | Turning ideas into working, tested scripts |
| 4 | [Section Drafting](04-section-drafting.md) | Producing first drafts with reviewer defense |
| 5 | [Verification Audit](05-verification-audit.md) | Catching errors before anyone else sees them |

## How to Use

1. **Copy the prompt** into your LLM conversation.
2. **Replace** `[BRACKETED FIELDS]` with your specific content.
3. **Iterate.** The first output is never final. Review, redirect, and re-run 3-5 times per section.
4. **Verify.** Every quantitative claim must be reproducible. Every derivation must pass a reality check. Every draft must survive a verification audit.
