# Prompt 4: Section Drafting

> *Use this to produce a first draft of any paper section — with preemptive reviewer defense.*

```
Draft a [SECTION TYPE] for a paper on [TOPIC]. The section should cover:

[KEY POINTS — list 3-6 specific things this section must include]

Use the following references: [REFS — provide author, year, and the
specific finding you want cited].

Style guidelines:
- Academic but accessible. Avoid jargon where a simpler term works.
- Follow [JOURNAL] conventions for citation format and section structure.
- Each paragraph should make exactly one point. Lead with the point.

After the draft:
(a) Flag any claims that need verification — mark them with [VERIFY].
(b) List 3 things a reviewer might criticize about this section.
(c) For each criticism, suggest how to address it in revision.
```

### When to Use

- Writing an introduction, methods, results, or discussion section
- Converting bullet points or notes into prose
- When you know what you want to say but need help with structure and flow

### What to Watch For

- The LLM's "academic but accessible" style can drift toward bland. Edit for voice.
- The preemptive reviewer critique is valuable — but only if you actually address the issues it raises.
- Use this for first drafts only. The human should always be the final editor.
