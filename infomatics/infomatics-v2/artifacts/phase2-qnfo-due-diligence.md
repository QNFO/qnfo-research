## §1. Methodology

Every QNFO paper identified in the 7 claim domains is classified against external evidence from Phase 1 (65 verified arXiv citations). The classification uses the Laws of Form distinction-theoretic framework.

**Three dimensions of classification:**

| Dimension | Question |
|:----------|:---------|
| **Distinction Class** | Is this distinction DRAWN, DEFINED, INFERRED, or HORIZON in the QNFO framework? |
| **External Mapping** | Does an equivalent distinction exist in the external literature? |
| **Citation Status** | How many non-QNFO citations does this paper have? |

## §10. The Infomatics v2 Classification Applied to QNFO

Every QNFO paper, like every external paper, receives:
- **Distinction class** within its framework
- **External recognition** (Established / Active / Noted / None)
- **Metrology scale** (what resolution required to draw the distinction)
- **Tree depth** (where in the ultrametric hierarchy)

| LoF Class | Distinction Tree Position |
|:----------|:--------------------------|
| QNFO — Falsifiable | Node is LABELED within QNFO tree. Parent distinctions are DEFINED. Falsification path is mapped. The node exists — external groups haven't visited it yet. |
| QNFO — Philosophical | Node is LABELED but has no falsification path. It is an organizing distinction (like "information is fundamental") that enables other claims but cannot itself be DRAWN. |
| QNFO — DEFINED externally | Node exists in BOTH the QNFO tree and the external tree. QNFO extends it into new subtrees that external groups haven't explored. |
