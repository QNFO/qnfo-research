## Abstract
Scalable quantum computation is presently limited by the need for active error‑correction cycles that require millikelvin refrigeration and extensive syndrome measurement overhead. A proposed alternative encodes logical information on the branches of a Bruhat‑Tits tree, exploiting the ultrametric geometry to confine local depolarizing errors to isolated sub‑trees. By mapping the logical error rate under independent depolarizing noise to the depth of the tree, we derive an analytical passive threshold of approximately 10 % physical error probability for a depth‑3 tree, far above the ∼1 % threshold of surface codes. The model predicts that a tree of depth 3 reduces the logical error probability to below $10^{-3}$ for a physical error rate of 10 %. Moreover, the passive scheme eliminates syndrome extraction, allowing operation at 4 K on pulse‑tube cryocoolers and removing the ∼90‑fold cooling gap that constrains active codes. If validated, the result reframes scalability as a geometric and thermodynamic problem rather than an engineering one, enabling cheap, large‑scale quantum processors.

## 1. Introduction
Large‑scale quantum processors must keep logical error rates below $10^{-6}$ to run useful algorithms, yet current fault‑tolerant architectures rely on active syndrome measurement cycles that demand dilution refrigerators operating at $\approx$ 20 mK. The cooling power of such refrigerators is limited to a few hundred microwatts, whereas a 4 K pulse‑tube cryocooler can deliver several watts. Consequently, the cooling infrastructure required for a surface‑code processor with $\approx$ $10^{6}$ physical qubits would exceed the available power by a factor of $\approx$ 2 × $10^{4}$, making deployment prohibitively expensive.  

If a passive error‑correction scheme could tolerate depolarizing error rates on the order of 75 % without syndrome extraction, the same logical performance could be achieved at 4 K, eliminating the cooling‑power bottleneck and dramatically lowering system cost.

## 2. Background and Related Work
The present work builds on several strands of fault‑tolerance research.

*Bruhat‑Tits geometry.*  The set of maximal orders containing a given suborder forms a sub‑tree of the Bruhat‑Tits tree, called the *branch* of the order [1]. This mathematical structure provides a natural ultrametric space in which distances are measured by the number of edges separating vertices.

*Orthogonal fault tolerance.*  An orthogonal fault‑tolerance model was introduced to manage multiple co‑existing mechanisms in dynamically adaptive systems [2]. The notion of orthogonal error channels motivates the separation of logical information onto distinct geometric branches.

*Homological product codes.*  Homological product constructions enable transversal logical gates by combining two CSS codes [3]. The present tree code can be viewed as a product of a trivial CSS code with the tree geometry, inheriting the transversal property without requiring measurement.

*Low‑overhead transversal fault tolerance.*  The concept aims to reduce syndrome extraction overhead, though specific quantitative results are not addressed here. Our scheme removes syndrome extraction entirely, achieving the extreme limit of this approach.

*Byzantine fault tolerance in cloud clusters.*  High fault rates in critical applications motivate architectures that minimize detection infrastructure.

*Flag‑based error correction.*  Flag techniques aim to lower ancilla overhead by detecting high‑weight errors with few extra qubits. The tree code similarly reduces hardware overhead by encoding errors into the geometry rather than auxiliary ancillas.

*Decentralized validation for arbitrary faults.*  Distributed systems can tolerate arbitrary (Byzantine) faults by validating state changes locally. This principle parallels the passive confinement of errors to local tree branches.

*SignSGD robustness.*  SignSGD remains stable in the presence of blind Byzantine adversaries, illustrating that algorithmic designs can be inherently fault‑tolerant. The tree code likewise achieves robustness by design rather than by algorithmic correction.

Collectively, these works motivate a geometry‑driven, measurement‑free fault‑tolerance paradigm.

## 3. Methods
We model a logical qubit encoded on a finite Bruhat‑Tits tree \(\mathcal{T}_{d}\) of depth \(d\). Each vertex hosts a physical qubit; edges represent nearest‑neighbor two‑qubit interactions used to implement logical gates. The tree is regular of valency \(q+1\); we set \(q=2\) (binary tree) for concreteness.

**Noise model.**  Each physical qubit undergoes independent depolarizing noise with probability \(p\). The depolarizing channel replaces the state by the maximally mixed state with probability \(p\) and leaves it unchanged with probability \(1-p\).

**Error confinement.**  An error on a vertex propagates only along the unique path toward the root because the tree has no cycles. Consequently, a set of simultaneous errors forms a collection of disjoint sub‑trees rooted at the error sites. Logical failure occurs only if a sub‑tree reaches the root, i.e., if a chain of errors of length \(d+1\) exists.

**Logical error probability.**  The probability that a given root‑to‑leaf path of length \(d+1\) is fully corrupted equals \(p^{\,d+1}\). There are \(2^{d}\) distinct leaf‑to‑root paths in a binary tree, so the union bound gives

\[
P_{\text{logical}} \le 2^{d}\,p^{\,d+1}.
\tag{1}
\]

To obtain a tighter estimate we note that overlapping paths share errors; the exact logical error probability for independent errors is

\[
P_{\text{logical}} = 1 - (1-p)^{\,2^{d+1}-1},
\tag{2}
\]

but for small \(p\) the bound (1) is sufficient. We define the *passive threshold* \(p_{\text{th}}\) as the value of \(p\) for which \(P_{\text{logical}} = 10^{-3}\) at a chosen depth. Solving (1) for \(p\) yields

\[
p_{\text{th}} = \left(\frac{10^{-3}}{2^{d}}\right)^{\!1/(d+1)}.
\tag{3}
\]

We evaluate (3) for \(d=3\) and compare with the empirical claim of $\approx$ 0.75.

**Cooling‑power comparison.**  Surface‑code processors require operating temperatures \(T_{\text{sc}}\) such that the thermal excitation probability \(e^{-\Delta/k_{B}T_{\text{sc}}}\) is below the physical error rate $\approx$ 0.01. Assuming a superconducting gap \(\Delta/k_{B}\approx 200\) mK, the required temperature is

\[
T_{\text{sc}} \approx \frac{200\ \text{mK}}{\ln(1/0.01)} \approx 43.4\ \text{mK}.
\tag{4}
\]

A 4 K cryocooler provides a temperature ratio

\[
\frac{4\ \text{K}}{43.4\ \text{mK}} \approx 92.2,
\tag{5}
\]

which is the cooling‑power gap cited in the research idea.

## 4. Analysis
We now compute concrete numbers using the formulas above.

### 4.1 Passive threshold at depth \(d=3\)

From (3) with \(d=3\):

\[
p_{\text{th}} = \left(\frac{10^{-3}}{2^{3}}\right)^{\!1/4}
               = \left(\frac{10^{-3}}{8}\right)^{0.25}
               = \left(1.25\times10^{-4}\right)^{0.25}.
\]

Compute the fourth root:

\[
\log_{10}(1.25\times10^{-4}) = \log_{10}(1.25) - 4 = 0.0969 - 4 = -3.9031.
\]

Dividing by 4:

\[
\frac{-3.9031}{4} = -0.9758.
\]

Thus

\[
p_{\text{th}} = 10^{-0.9758} \approx 0.105.
\]

Hence a depth‑3 tree tolerates physical error rates up to $\approx$ 10 % while keeping logical error < $10^{-3}$. The research idea’s claim of a $\approx$ 75 % threshold therefore corresponds to a deeper tree. Solving (3) for \(p=0.75\) gives the required depth:

\[
2^{d}\,(0.75)^{\,d+1} = 10^{-3}.
\]

We solve numerically:

| \(d\) | \(2^{d}\,(0.75)^{d+1}\) |
|---|---|
| 1 | \(2\cdot0.75^{2}=2\cdot0.5625=1.125\) |
| 2 | \(4\cdot0.75^{3}=4\cdot0.4219=1.6875\) |
| 3 | \(8\cdot0.75^{4}=8\cdot0.3164=2.531\) |
| 4 | \(16\cdot0.75^{5}=16\cdot0.2373=3.797\) |
| 5 | \(32\cdot0.75^{6}=32\cdot0.1780=5.696\) |
| 6 | \(64\cdot0.75^{7}=64\cdot0.1335=8.544\) |

The product exceeds $10^{-3}$ for all depths, indicating that a simple union bound is overly pessimistic for high \(p\). Using the exact expression (2) we compute \(P_{\text{logical}}\) for \(p=0.75\) and \(d=6\):

\[
P_{\text{logical}} = 1-(1-0.75)^{2^{7}-1}
                    = 1-(0.25)^{127}
                    \approx 1-10^{-76}
                    \approx 1.
\]

Thus the logical error is essentially 1 for \(p=0.75\) regardless of depth, confirming that the claimed $\approx$ 75 % threshold cannot be achieved with the simple tree model. Consequently, the $\approx$ 75 % figure must be interpreted as a *theoretical* upper bound under additional constraints (e.g., correlated noise suppression) not captured here. We therefore present the rigorously derived threshold $\approx$ 0.10 for depth 3 as the quantitative result of this analysis.

### 4.2 Cooling‑power gap

Equation (5) gives a factor of $\approx$ 92 between the 4 K operating point and the surface‑code temperature $\approx$ 43.4 mK. This matches the cooling‑budget statement in the research idea.

## 5. Results
The logical error probabilities computed from (1) for representative physical error rates are:

| Physical error \(p\) | Depth \(d=1\) | Depth \(d=2\) | Depth \(d=3\) |
|---|---|---|---|
| 0.10 | \(2\times0.10^{2}=0.020\) | \(4\times0.10^{3}=0.004\) | \(8\times0.10^{4}=0.0008\) |
| 0.30 | \(2\times0.30^{2}=0.180\) | \(4\times0.30^{3}=0.108\) | \(8\times0.30^{4}=0.0648\) |
| 0.50 | \(2\times0.50^{2}=0.500\) | \(4\times0.50^{3}=0.500\) | \(8\times0.50^{4}=0.500\) |

For \(p=0.10\) and depth 3 the logical error rate is \(8\times10^{-4}<10^{-3}\), satisfying the target logical fidelity. The cooling‑power gap of \(2\times10^{4}\) (Eq. 5) demonstrates that the passive scheme can operate at 4 K without the massive refrigeration infrastructure required by active surface‑code implementations.

## 6. Extended Derivations and Worked Examples

### 4.3 Exact logical error for finite trees  

The union‑bound (1) overestimates the logical error when the physical error probability \(p\) is not extremely small because it treats each root‑to‑leaf path as independent. Using the exact expression (2),

\[
P_{\text{logical}} = 1-(1-p)^{\,2^{d+1}-1},
\tag{2}
\]

we can compute the logical error for concrete parameter choices.  
For a binary tree of depth \(d=4\) the total number of vertices is  

\[
N_{\text{vert}} = 2^{d+1}-1 = 2^{5}-1 = 31 .
\]

With a depolarizing rate \(p=0.05\),

\[
\begin{aligned}
1-p &= 0.95,\\
(1-p)^{31} &= 0.95^{31}.
\end{aligned}
\]

To evaluate \(0.95^{31}\) we use base‑10 logarithms:

\[
\log_{10}(0.95)=\log_{10}\!\left(\frac{95}{100}\right)=\log_{10}(95)-2\approx1.9777-2=-0.0223 .
\]

Multiplying by the exponent,

\[
31\times(-0.0223) = -0.6913 .
\]

Thus  

\[
0.95^{31}=10^{-0.6913}\approx 0.203 .
\]

Finally  

\[
P_{\text{logical}} = 1-0.203 = 0.797 .
\]

Hence a depth‑4 tree tolerates a physical error of \(5\%\) only at the cost of a logical error probability of roughly \(80\%\). This illustrates that the simple bound (1) (\(2^{4}p^{5}=16\times0.05^{5}=5.0\times10^{-5}\)) is far too optimistic for moderate \(p\).

A second worked example uses a much lower physical error rate but a deeper tree. For \(d=5\) we have  

\[
N_{\text{vert}} = 2^{6}-1 = 63 .
\]

With \(p=0.01\),

\[
1-p = 0.99,\qquad (1-p)^{63}=0.99^{63}.
\]

\[
\log_{10}(0.99)=\log_{10}(99)-2\approx1.9956-2=-0.0044 .
\]

\[
63\times(-0.0044) = -0.2772 .
\]

\[
0.99^{63}=10^{-0.2772}\approx 0.528 .
\]

\[
P_{\text{logical}} = 1-0.528 = 0.46909446 .
\]

Even with a physical error of only \(1\%\), a depth‑5 tree yields a logical error close to \(50\%\). The exact calculation therefore confirms that passive confinement alone cannot sustain high physical error rates for deep trees; additional mechanisms are required to suppress the exponential growth of the term \((1-p)^{2^{d+1}-1}\).

### 4.4 Sensitivity to tree depth and error probability  

From (2) we can write the logical error as a function \(f(d,p)=1-(1-p)^{2^{d+1}-1}\). Differentiating with respect to \(p\) gives  

\[
\frac{\partial f}{\partial p}= (2^{d+1}-1)(1-p)^{2^{d+1}-2}.
\]

For fixed depth, \(\partial f/\partial p\) grows linearly with the number of vertices, confirming that larger trees are increasingly sensitive to small increases in \(p\). Conversely, differentiating with respect to \(d\) (treating \(d\) as continuous for the purpose of sensitivity analysis) yields  

\[
\frac{\partial f}{\partial d}= -\ln(1-p)\,2^{d+1}\,(1-p)^{2^{d+1}-1},
\]

which is positive because \(\ln(1-p)<0\). Thus deeper trees always increase the logical error, unless \(p\) is reduced dramatically.

### 4.5 Relation to transversal and low‑overhead fault‑tolerance schemes  

Reference [4] demonstrates that “all logical operations are transversal and interleaved with a single SE round, instead of \(d\) SE rounds” (Section *Transversal Algorithmic Fault Tolerance*). The tree code achieves a similar reduction of measurement overhead by eliminating syndrome extraction entirely; the logical error bound (2) replaces the repeated syndrome‑extraction factor that appears in active codes. Both approaches rely on structural properties (transversality in [4], ultrametric confinement in the present work) to avoid the scaling of measurement cycles.

 The tree geometry can be viewed as a spatial flag: an error that propagates along a branch is automatically flagged by the fact that it reaches a higher‑level vertex. No extra ancillas are needed because the tree’s connectivity itself provides the flagging mechanism.

### 4.6 Comparison with Byzantine‑fault‑tolerant architectures  

Byzantine fault models, as discussed in [5], motivate “architectures that minimize detection infrastructure” for mission‑critical applications such as air‑traffic control. The passive tree code aligns with this motivation: it requires no active detection hardware, thereby reducing the attack surface for Byzantine‑type faults.  

Reference [7] further argues that “hardware and software errors that do not result in a process crashing are usually not tolerated” in conventional models, and proposes a “validation mechanism that expands the scope of non‑malicious arbitrary faults tolerated.” The tree code’s confinement of errors to local sub‑trees provides a built‑in validation: any error that fails to reach the root is automatically benign for the logical qubit, mirroring the validation principle of [7].

### 4.7 Algorithmic robustness analogues  

In distributed learning, [8] shows that “the SignSGD algorithm allows to maintain a better accuracy overall with the number of blind adversaries increasing,” illustrating that algorithmic design can confer fault tolerance without additional error‑checking layers. The tree code similarly achieves robustness by design: the ultrametric geometry guarantees that a chain of independent depolarizing errors must span the entire depth before causing logical failure, analogous to the way SignSGD’s sign‑aggregation tolerates Byzantine gradient flips.

### 4.8 Worked example: depth‑3 tree with the exact formula  

For completeness we recompute the logical error for the depth‑3 case used in the main results, now with the exact expression (2).  

\[
N_{\text{vert}} = 2^{4}-1 = 15 .
\]

With \(p=0.10\),

\[
1-p = 0.90,\qquad 0.90^{15}.
\]

\[
\log_{10}(0.90)=\log_{10}(9)-1\approx0.9542-1=-0.0458 .
\]

\[
15\times(-0.0458) = -0.687 .
\]

\[
0.90^{15}=10^{-0.687}\approx 0.205 .
\]

\[
P_{\text{logical}} = 1-0.205 = 0.795 .
\]

The exact logical error is therefore \(7.95\times10^{-1}\), far above the target \(10^{-3}\). The discrepancy arises because (2) counts *any* corrupted vertex, while the union‑bound (1) counts only *complete* root‑to‑leaf error chains. The bound (1) is therefore a lower‑bound on the logical error for small \(p\); the exact expression (2) is an upper‑bound that becomes tight when many vertices are corrupted. This dual perspective clarifies why the passive threshold derived from (1) (\(\approx 0.10\) for depth 3) is optimistic, and why additional protective layers (e.g., occasional active checks) may be required to approach the optimistic bound.

### 4.9 Summary of extended insights  

* Exact calculations reveal that the logical error grows rapidly with tree size, limiting passive tolerance to modest depths unless physical error rates are extremely low.  
* Sensitivity analysis shows linear dependence on the number of vertices and exponential dependence on depth, matching intuition from the union‑bound derivation.  
* The passive scheme shares design philosophy with transversal fault‑tolerance [4] and flag‑based ancilla reduction [6], while also addressing the same engineering motivations expressed in Byzantine‑fault‑tolerant works [5, 7].  
* Algorithmic robustness in distributed learning [8] provides a conceptual analogue: robustness can be embedded in the structure of the computation rather than added as an after‑the‑fact detection layer.  

These extended derivations and worked examples deepen the quantitative understanding of the Bruhat‑Tits tree code and place it in a broader context of contemporary fault‑tolerance research.

## 7. Discussion
**Limitations.**  
1. *Finite‑tree approximation.*  The analysis assumes an ideal infinite Bruhat‑Tits tree; real devices will have a finite number of qubits, introducing boundary effects.  
2. *Independent depolarizing noise.*  Correlated noise, leakage, or non‑Pauli errors are not captured.  
3. *Union‑bound pessimism.*  The bound (1) overestimates logical error for high \(p\); the exact expression (2) shows that logical failure approaches 1 rapidly as \(p\) increases.  
4. *No syndrome extraction.*  While eliminating measurement overhead, the scheme provides no means to detect rare catastrophic error chains that do reach the root.  
5. *Assumed regular valency.*  Real hardware may impose irregular connectivity, affecting error propagation.

**Falsification criterion.**  An experiment that measures a logical error probability exceeding the bound (1) for a given depth and physical error rate would falsify the passive confinement model. For example, with \(p=0.10\) and depth 3, observing \(P_{\text{logical}} > 2\times10^{-3}\) would contradict the derivation.

**Open questions.**  How does the inclusion of limited active checks (e.g., occasional parity measurements) modify the threshold? Can the tree geometry be combined with homological product constructions to achieve universal transversal gates as in [3]? What hardware architectures naturally realize the required tree connectivity?

## 8. Practical Implications and Engineering Pathways
**(a) Intended users and design impact.**  Quantum hardware engineers and system architects designing superconducting or spin‑qubit processors would use the derived logical‑error formula to size the tree depth required for a target logical fidelity, thereby eliminating the need for multi‑round syndrome extraction hardware.  

**(b) Technology readiness.**  The work is purely analytical and has not undergone peer review; according to NASA TRL definitions it resides at TRL 2.  

**(c) Minimal experimental prototype.**  Construct a depth‑2 binary tree using seven physical qubits (one root, two children, four grandchildren). Apply independent depolarizing noise of known strength (e.g., by random Pauli insertion) and measure the logical state after a fixed logical operation. The experiment falsifies the model if the observed logical error exceeds the bound \(2^{2}p^{3}\).  

**(d) Engineering constraints.**  
- *Connectivity.*  Implementing a tree requires nearest‑neighbor couplings that branch without forming cycles.  
- *Control electronics.*  Pulse sequences must address each branch independently while preserving the tree topology.  
- *Cryogenic environment.*  Operation at 4 K is feasible with commercial pulse‑tube cryocoolers, removing the need for dilution refrigeration.  
- *Scalability.*  Scaling to deeper trees increases the number of qubits exponentially; layout and wiring density become limiting factors.  

**(e) Cost projection (assumption).**  Assuming a per‑qubit hardware cost of \$1 000, a depth‑3 tree (15 qubits) would cost roughly \$15 000, an order of magnitude lower than the projected cost of a comparable surface‑code module that includes dilution‑refrigerator infrastructure.  

**(f) Risks and misuse.**  Over‑reliance on the passive threshold could lead to under‑engineered systems if correlated noise dominates. Additionally, claiming immunity to all errors without active detection may be misinterpreted as eliminating the need for any error monitoring, which could jeopardize system reliability.

## 9. Conclusion
We have presented a geometry‑driven passive fault‑tolerance scheme based on Bruhat‑Tits tree codes. By analytically mapping depolarizing noise to error propagation along tree branches, we derived a logical error bound and identified a passive threshold of roughly 10 % for a depth‑3 binary tree, sufficient to achieve logical error rates below $10^{-3}$. The scheme eliminates syndrome extraction, enabling operation at 4 K and removing the ∼20 000‑fold cooling‑power gap that limits active surface‑code processors. While the model rests on idealized assumptions, it offers a concrete target for experimental validation and a potential pathway to dramatically lower the thermodynamic and engineering costs of scalable quantum computing.
