## Elevator Pitch

Computable real numbers (Turing 1936) form a countable subset of ℝ. Every number ever used in physics — π, e, √2, the fine-structure constant — is computable. Non-computable reals (Chaitin's Ω, etc.) have never appeared in any physical prediction. This project formalizes the argument that **computable reals constitute the boundary between physics (grounded by measurement and falsifiability) and mathematics/creative fiction (internally consistent but physically vacuous)**. A physical theory requiring a non-computable real number would be fundamentally untestable — because no finite measurement could distinguish that real from a computable approximation — and thus fails the falsifiability requirement that defines physics. This is not a limitation on physics; it is a recognition of what physics is.
