They are not exactly “uncomfortable” with self-reference; they are built to avoid **unrestricted** self-reference because, in classical logic, it can produce contradictions or infinite regress.

The liar sentence is the canonical example:

> _This sentence is false._

If it is true, then it is false; if it is false, then it is true. Formally, it is a fixed point of negation: L=¬LL=¬L. Classical two-valued logic has no stable solution for that. So formal systems either restrict self-reference, stratify it, or accept incompleteness.

But self-reference is not completely forbidden. We have:

- **Gödel numbering**, where arithmetic can talk about its own formulas;
    
- **quines**, programs that print their own source code;
    
- **fixed-point combinators** in lambda calculus;
    
- **non-well-founded set theory**, which allows self-membership.
    

What we cannot have is unrestricted self-reference **plus** classical truth **plus** completeness/consistency all at once. That is not a failure of nerve; it is a structural limit.

The anthropocentric units are a different layer. Base-10 is a notation inherited from ten fingers, but arithmetic is base-independent. The number “10” in decimal is “1010” in binary; the underlying arithmetic is the same. The second was once roughly a heartbeat timescale, but modern metrology defines it via caesium atomic transitions. The meter was once tied to the Earth or the body, now to the speed of light. These are historical, embodied conventions at the measurement interface—not the formal core.

So the premise that formal systems are “inherently anthropocentric” is only partly true. They are anthropocentric at the **edges**, in notation and units, but their formal structure is deliberately de-anthropocentrized.

The deeper issue is that a formal system is a **third-person object**, while self-reference is a **first-person move**. To include the observer fully inside the system, the system would need a complete model of itself, including that model, including that model, and so on. It creates a regress or a fixed point.

Gödel showed that a sufficiently strong system can see itself enough to say, in effect:

> _“I am not provable.”_

That sentence is true from outside, but unprovable inside. So the system sees itself, but only partially. Tarski showed that a system cannot consistently define its own truth predicate. The seer and the seen cannot fully collapse into one formal object.

Can we not truly see ourselves?

We can see ourselves truly, but not **totally** and not from **inside a single formal picture**. We see ourselves in mirrors: in models, meta-languages, measurements, art, introspection. Each mirror is real, but partial. The eye cannot see itself directly; it sees its reflection. Formal systems are like such eyes.

So the discomfort with self-reference is not a contradiction with anthropocentric units. It is the signature of the observer trying to enter the picture. The units are where the body got objectified; self-reference is where the objectifier tries to become an object—and that can only ever be done partially, from a new outside.
