## What this is

A cross-program methodological scaffold for QNFO research. It fixes:

1. **The pre-arithmetic ladder (D0–D8)** — distinction → pre-arithmetic → arithmetic → number
   theory → valuation → geometry → information → measurement → physics. Every research object
   declares its level.
2. **Two hard gates** — G1 ONTIC-GATE: distinction is a methodological primitive unless an
   explicit, per-claim, pre-registered ontic commitment is made. G2 REALIZATION-GATE: a
   mathematical isomorphism is a map, not a territory; passing to physical realization requires a
   pre-specified measurement protocol, null model, and falsification condition.
3. **A reusable claim taxonomy** — one field schema (`level`, `carrier`, `ontic_commitment`,
   `map_territory`, `protocol`, `null_model`, `falsifier`, `reporting_rule`) attachable to any
   program's pre-registration without changing its WBS structure.
