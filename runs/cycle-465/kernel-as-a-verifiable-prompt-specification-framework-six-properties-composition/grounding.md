## Research idea

Formalizing KERNEL as a Verifiable Prompt Specification Framework. Claim: prompt effectiveness is governed by six orthogonal, formalizable properties—simplicity, verifiability, reproducibility, narrow scope, explicit constraints, and structured format—which can be modeled as constraints on a prompt specification rather than heuristics. A paper could formalize each KERNEL component (e.g., verifiability as machine-checkable success criteria, scope as single-goal decomposition, reproducibility as invariance to temporal context) and test whether they predict LLM output quality. Method: construct a benchmark of prompt pairs (KERNEL-compliant vs. non-compliant) across tasks and models, run controlled experiments measuring first-try success, revision counts, token cost, and output consistency over time, and fit a regression/ablation analysis to isolate each component's contribution. A formal analysis could also prove that chaining narrow, verifiable sub-prompts composes better than monolithic prompts, connecting prompt design to program decomposition and contract-based verification.
