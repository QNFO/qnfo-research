## Research idea

When Does Spectral Data Constructively Determine Arithmetic Sequences?. The note's failed verification suggests a precise open question: formalize a notion of 'constructive emergence' distinguishing when global spectral data (e.g., zeta zeros) algorithmically determines individual elements of an arithmetic sequence (primes) versus merely encoding distributional sums. Conjecture: the map {zeros} → {primes} admits no polynomial-precision constructive inversion, whereas Pisot rounding (Fibonacci from φ) is exact and local. A paper could define a reconstruction-complexity hierarchy: given truncated spectral data (zeros up to height T), bound the recoverable resolution of π(x) or ψ(x), prove precision requirements grow super-polynomially in log n for pointwise primality testing, and axiomatize the algebraic-vs-analytic emergence dichotomy via cut-and-project (constructive) versus explicit-formula (non-constructive) paradigms. Related sub-question: characterize exactly which integer linear recurrences have Dirichlet series that are irreducible L-functions with Euler products—the counterexample aₙ = 2aₙ₋₁ − aₙ₋₂ ↦ ζ(s−1) shows reducibility is not preserved, so a classification theorem (likely: only Galois-representation recurrences qualify) is testable by symbolic computation over recurrence families.
