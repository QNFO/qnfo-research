## Research idea

Ultrametric Tree Encoding Confines Quantum Errors via Strong Triangle Inequality. Encoding qubits on a Bruhat–Tits tree (ultrametric geometry) should geometrically confine errors: the strong triangle inequality d(x,z) ≤ max(d(x,y), d(y,z)) prevents errors in one subtree from propagating to distant branches, yielding zero logical error rate at depth ≥ 3, unlike flat/surface-code layouts. This matters because it suggests topology of the encoding space, not just code distance, controls error propagation. A paper could test it by formalizing error propagation as paths on the tree and proving confinement from the ultrametric axiom, then running Monte Carlo noise simulations comparing logical error rates and error-location distributions against surface codes, checking whether the claimed LER = 0 holds under realistic noise models or is an artifact of the demo's noise assumptions.
