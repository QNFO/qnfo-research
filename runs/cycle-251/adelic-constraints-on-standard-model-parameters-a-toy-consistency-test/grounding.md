## Research idea

Ruler independence: adelic constraints forcing Standard Model parameters to be algebraic. Conjecture: if fundamental law is defined over Q and must be consistent under every completion (R and all Q_p), then Standard Model free parameters cannot be arbitrary reals; adelic product formulas (real component times all p-adic components fixed by anomaly cancellation or topology) force them to be rational or algebraic, making constants calculable. Precedent: adelic p-adic string theory fixed the string coupling via the product formula. Test: derive an adelic consistency condition for a simplified sector (e.g., a U(1) coupling or one Yukawa), showing the real-place value equals the inverse p-adic product, and check whether the resulting number matches the measured fine-structure constant or a mass ratio without tuning; alternatively simulate ultrametric dynamics to see if Archimedean physics emerges as a macroscopic limit.
