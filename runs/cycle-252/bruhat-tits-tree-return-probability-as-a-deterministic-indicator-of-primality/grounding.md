## Research idea

Bruhat-Tits Tree Return Probability as Deterministic Primality Indicator. Claim: encoding an integer N as an automorphism of the p=2 Bruhat-Tits tree, the simple random walk's return probability behaves qualitatively differently for primes versus composites: primes yield a confined, periodic walk with return probability spiking to 1 (discrete Laplacian spectrum, nonzero spectral gap), while composites yield a transient walk whose return probability decays smoothly to zero (continuous spectrum, zero gap). The author conjectures that observing the early-time derivative of the return probability—oscillating versus monotone decay—certifies primality deterministically in few steps, unlike probabilistic Miller-Rabin. This matters because it would link arithmetic of N to spectral geometry of non-Archimedean buildings, giving a spectral-geometric primality test. Testable: rigorously define the N-dependent walk/laplacian, prove or disprove recurrence for prime-induced automorphisms and transience for composites; numerically compute heat kernels and spectral gaps for many N to check whether the claimed oscillation/decay dichotomy actually separates primes from composites, or whether the schematic conflates distinct constructions.
