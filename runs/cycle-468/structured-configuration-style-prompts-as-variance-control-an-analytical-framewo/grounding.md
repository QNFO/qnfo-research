## Research idea

Structured Configuration-Style Prompts Reduce Cross-LLM Output Variance. The author conjectures that prose-style instructions are inherently ambiguous, causing divergent interpretations across LLMs, while rigid, configuration-file-style prompts (explicit IF/THEN protocols, schemas, state machines) enforce deterministic, consistent execution across any compliant model. This is a testable empirical claim about prompt formalism and output variance. A study could define paired prompt corpora—one prose, one structured—describing identical tasks, run each through multiple LLMs under fixed temperature, and measure inter-model agreement (output structural similarity, semantic equivalence, schema compliance rates) and intra-model consistency across seeds. Formal analysis could model prompts as programs and ambiguity as interpretation divergence, predicting variance reduction from syntactic constraint density. If structured prompts significantly reduce cross-model variance, prompt engineering becomes a reproducible specification discipline rather than a literary craft.
