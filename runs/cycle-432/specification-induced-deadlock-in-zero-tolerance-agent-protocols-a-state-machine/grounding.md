## Research idea

Specification-Induced Deadlock in Zero-Tolerance Agent Protocols. Conjecture: agent protocols that mandate live tool execution with zero tolerance for simulated or placeholder actions can induce a deadlock state: the agent recognizes the required capability exists in its action space but is not invoked in the current operational context, so it classifies any attempted action as a forbidden simulation and halts. The protocol lacks a middle state for 'tools available but not used in this instance.' Why it matters: this catch-22 is a specification-level failure mode, not a capability failure, and may generalize to other strict-verifiability protocols. Test: formalize the protocol's failure conditions as a state machine over (requirement, capability, invocation) triples and prove the halt state is reachable and unavoidable under zero-tolerance semantics; empirically, run LLM agents under such protocols across varied tool-availability configurations and measure halt rates, showing deadlocks occur precisely when capability exists but invocation is blocked.
