# Human Perception of AI-Generated Writing

Research project (QNFO.RES.002) synthesizing the empirical literature on how humans perceive AI-generated writing — where the text is itself a statistical re-composition of human writing.

**Scope:** Perception evidence (detection, label effects, algorithm aversion/appreciation, uncanny-valley transfer) + the *synthesis-from-human-writing* framing + connection to QNFO's AI-QUALITY-GATE-1 / disclosure strategy.

**Status:** Phase 0 (init) — see `PROJECT-PLAN.md`.
