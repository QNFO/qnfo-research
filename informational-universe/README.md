# The Informational Universe

**QNFO.INM.001** · Information-physics program

## Core Claim (locked at Phase 0)

Information — the structure of distinctions — is the primary substrate of
physics. Physical law is the constraint structure governing how distinctions
can be drawn, related, and communicated by observers.

## Research Question

What is the minimal set of information-theoretic principles from which the
observable structure of physics follows — quantum mechanics, thermodynamics,
measurement, and the adelic number structure?
