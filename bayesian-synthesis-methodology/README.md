# Bayesian Synthesis Methodology (BSM) — QNFO.RES.001

A methodological framework for Bayesian guardrails in cross-domain scientific synthesis, with a self-critical audit of the Adelic Core Synthesis framework's predictive status as case study.

**Status:** Phase 0 (initialization)
**WBS:** QNFO.RES.001
**Branch:** res/paper/bayesian-synthesis-methodology

## Core Claim

Bayesian reasoning is the only guardrail that distinguishes genuine cross-domain consilience from retrospective storytelling. Applied to the Adelic Core Synthesis, the framework scores near-zero Bayesian weight for post-dictions and pending for 5 falsifiable forward predictions — it is a research programme, not a fully specified predictive model.
