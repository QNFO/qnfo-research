# Signal-Worker Boundary Confinement

**QNFO.INM.001** — A corrected ontology of surface vs bulk transport.

A 3-slot red-team audit (2026-08-14) found its boundary-confinement reading overgeneralizes the genuine surface-vs-bulk physics of topological conductors. This project formalizes the corrected position.
