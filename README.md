# Joules-per-Compute Universal Benchmark (JPCUB)

**Status:** Phase 0 — Program Scaffold | **Started:** 2026-07-27
**Parent Series:** The Qubit Delusion (Phase VI Generalization)
**Preceded By:** BQNN v2 (DOI 10.5281/zenodo.21623218)

## Overview

The Joules-per-Compute Universal Benchmark (JPCUB) is a comprehensive research program that establishes **joules-per-solution** as the only honest arbiter of computational advantage — generalizing beyond quantum-classical comparisons to CPUs, AI accelerators, cryptographic systems, data centers, neuromorphic computing, and edge/IoT devices.

### Core Claim

> "Joules-per-solution is the only honest arbiter of computational advantage."

The universe does not care about FLOPs. It cares about joules.

### Scope

- **7 domain streams** (quantum, AI, crypto, data centers, CPUs, neuromorphic/thermodynamic, edge/IoT)
- **12 publishable papers** from foundational metric definition to synthesis atlas and policy recommendations
- **Cross-cutting methodology** for fair, reproducible, anti-gaming energy measurement
