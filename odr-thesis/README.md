# ODR Thesis — The Compton Count as Primitive

**Status:** Phase 0 (scaffold) | **Repo:** QNFO/odr-thesis

The Ontological Distribution of Reality (ODR) framework asserts that the Compton count \(N_C = m/m_P \in \mathbb{Q}^+\) is the only primitive physical quantity — every other quantity (wavelength, energy, action, coupling constants) is a rational function of it. The geometric realization of these rational valuations is the Bruhat–Tits tree: a purely combinatorial, origin-less, scale-less coordinate system.

This repository is the definitive synthesis paper addressing all five research questions as a single, unified ODR thesis.

## Research Questions

| # | Domain | Core Question |
|:--|:-------|:--------------|
| RQ1 | Ontological | Can every physical quantity be expressed as a rational function of \(N_C\)? |
| RQ2 | Foundational | Is the physical number system \(\mathbb{Q}\) rather than \(\mathbb{R}\)? |
| RQ3 | Coordinate | Can the BT tree replace Cartesian \(\mathbb{R}^3\) as the coordinate system of physics? |
| RQ4 | Predictive | Does this framework generate a testable Planck-scale prediction? |
| RQ5 | Meta-Scientific | Why did five disciplines discover the same tree independently — and what new physics emerges from connecting them? |
