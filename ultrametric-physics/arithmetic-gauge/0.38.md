### 3.2 Iteration Pattern

The iteration of $g_1$ reveals a general pattern:

$$?(x/(kx+1)) = ?(x)/(k+1)$$

This is because $g_1^k(x) = x/(kx+1)$, and $?(g_1^k(x)) = ?(g_1^{k-1}(x))/2 = \cdots = ?(x)/2^k$.

But $x/(kx+1)$ has denominator $k+1$ not $2^k$... wait, let me check this. Actually:
- $g_1(x) = x/(x+1)$ → $?(g_1(x)) = ?(x)/2$
- $g_1(g_1(x)) = (x/(x+1))/(x/(x+1)+1) = x/(2x+1)$ → $?(g_1^2(x)) = ?(x)/4$
- $g_1^3(x) = x/(3x+1)$ → $?(g_1^3(x)) = ?(x)/8$

So the general formula is: $?(x/(kx+1)) = ?(x)/2^k$, where $k$ is the iteration count. The denominator $2^k$ is the Thompson group element (dyadic scaling by $1/2^k$), and $x/(kx+1)$ is the PGL(2,Z) element.

### 3.3 Complement Pattern

$$g_3(x) = 1/(x+1) = 1 - (x/(x+1))$$

$$?(g_3(x)) = ?(1 - g_1(x)) = 1 - ?(g_1(x)) = 1 - ?(x)/2$$

This demonstrates that the complement operation $x \mapsto 1-x$ conjugates to $y \mapsto 1-y$ in ?-space.
