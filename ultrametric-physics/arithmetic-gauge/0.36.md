## 4. Refinement of the Projection Principle

### 4.1 Original Speculation (0.35.md §6.2)

> "For any subset $S \subset \mathbb{Q}$ with a well-defined constraint, the projected Euclidean distance distribution has kurtosis that **decreases** with constraint strength."

**This was WRONG.** The data shows the opposite: kurtosis **increases** with tree-ward constraint.

### 4.2 Corrected Principle: Tree Amplification

> **The more a subset respects tree structure (divisibility, modular arithmetic, Farey adjacency), the HEAVIER the tails of its projected Euclidean distance distribution. Tree-ward constraints AMPLIFY the metric mismatch signature, not dampen it.**

Unconstrained sets (all integers) have nearly uniform gaps (kurtosis ~0). Maximally tree-constrained pairs (Farey neighbors) have extreme heavy tails (kurtosis 951.5). Sets with intermediate tree structure fall on a spectrum between these extremes.

### 4.3 Why the Original Speculation Was Wrong

The original speculation (0.35.md) reasoned that "constraint filters out extreme events." This logic was backwards. The correct logic is:

1. Tree structure creates the heavy-tailed signature (metric mismatch)
2. Removing tree structure removes the signature (→ kurtosis 0 for all integers)
3. **Adding** tree structure (Farey adjacency, primarity, twin pairing) **adds** to the heavy-tailed signature

The Farey neighbor set (kurtosis 951.5) is MAXIMALLY tree-constrained — every pair is directly adjacent in the Stern-Brocot tree. This is not "filtering out extremes" — it's **selecting for the tree structure that produces extremes.**

### 4.4 Primarity as Tree Selection

Primes are depth-1 children of 1 in the divisibility tree. This selects a specific subset of tree nodes — those with maximal divisibility constraint. The kurtosis of 4.76 reflects the amount of tree structure retained by this selection. Twin primes add a further pairwise constraint (both are prime, and they're adjacent as integers), increasing kurtosis to 18.38.
