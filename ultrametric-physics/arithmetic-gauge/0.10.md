# p-adic Langlands and the Bruhat–Tits Building

**Companion note to the Kapustin–Witten Duality paper**

---

## 1. Orientation

The Kapustin–Witten construction lives in the Archimedean world: gauge theory on smooth manifolds, Riemann surfaces over $\mathbb{C}$, harmonic analysis on the upper half-plane. To approach the arithmetic Langlands program — which concerns Galois representations over p-adic fields — one must understand the **non-Archimedean analog**. The central geometric object in this analog is the **Bruhat–Tits building**, a combinatorial structure that replaces the Riemann surface / hyperbolic plane.

---

## 2. The p-adic Numbers

### 2.1 Definition

Fix a prime p. The **p-adic valuation** v_p: $\mathbb{Q} \to \mathbb{Z}$ ∪ {$\infty$} counts the power of p dividing a rational number:

```
v_p(p^k · a/b) = k    where p ∤ a, p ∤ b
v_p(0) = ∞
```

The **p-adic absolute value** is |x|_p = p^{−v_p(x)} (with |0|_p = 0). This satisfies the **ultrametric inequality**:

```
|x + y|_p ≤ max(|x|_p, |y|_p)
```

which is stronger than the triangle inequality. The field **$\mathbb{Q}$_p** is the completion of $\mathbb{Q}$ with respect to |·|_p. The ring of p-adic integers $\mathbb{Z}$_p = {x ∈ $\mathbb{Q}$_p : |x|_p ≤ 1} is a compact, open subring.

### 2.2 Topological Peculiarities

The ultrametric property implies that $\mathbb{Q}$_p is **totally disconnected** as a topological space: the only connected components are single points. Every open ball is also closed ("clopen"). This means $\mathbb{Q}$_p looks nothing like $\mathbb{R}$ — it is a Cantor-set-like space.

---

## 3. The p-adic Projective Line

The **p-adic projective line** ℙ$^1 \mathbb{Q}$_p) = $\mathbb{Q}$_p ∪ {$\infty$} is the set of lines through the origin in $\mathbb{Q}$_p$^2$ (equivalently, the set of $\mathbb{Z}$_p-lattices of rank 1 in $\mathbb{Q}$_p$^2$).

As a topological space, ℙ$^1 \mathbb{Q}$_p) is **totally disconnected** — it is homeomorphic to a Cantor set. However, it can be "thickened" to a connected object: the **Bruhat–Tits tree**.

---

## 4. The Bruhat–Tits Tree T_p

### 4.1 Definition via Lattices

A **lattice** in $\mathbb{Q}$_p$^2$ is a rank-2 $\mathbb{Z}$_p-submodule $\Lambda$ ⊂ $\mathbb{Q}$_p$^2$. Two lattices $\Lambda _1 \Lambda _2$ are **equivalent** (homothetic) if $\Lambda _1$ = p^k $\Lambda _2$ for some k ∈ $\mathbb{Z}$.

**Vertices:** The vertices of the tree T_p are the homothety classes [$\Lambda$] of lattices in $\mathbb{Q}$_p$^2$.

**Edges:** Two vertices [$\Lambda _1$] and [$\Lambda _2$] are joined by an edge if there exist representatives such that:

```
pΛ₁ ⊊ Λ₂ ⊊ Λ₁
```

(proper inclusions) with index [$\Lambda _1$ : $\Lambda _2$] = p.

### 4.2 Structure

- T_p is an infinite, **(p+1)-regular tree**: every vertex has exactly p+1 neighbors.
- For p = 2, it is a 3-regular tree. For p = 3, a 4-regular tree, etc.
- There is a natural **distance function** d(v, w) = number of edges on the unique geodesic between v and w.

### 4.3 The Boundary at Infinity

A **geodesic ray** in T_p is an infinite sequence of vertices v$_0$, v$_1$, v$_2$, … such that d(v_i, v_{i+1}) = 1 and v_i $\neq$ v_{i+2}. Two rays are equivalent if they eventually coincide. The set of equivalence classes is the **boundary** $\partial$T_p.

**Key fact:** $\partial$T_p ≅ ℙ$^1 \mathbb{Q}$_p). The Cantor set topology of ℙ$^1 \mathbb{Q}$_p) is exactly the topology induced on the boundary by the tree.

This is the p-adic analog of the identification $\partial$ℍ$^2$ ≅ ℙ$^1 \mathbb{R}$) = S$^1$ for the hyperbolic plane.

### 4.4 Group Action

The group GL(2, $\mathbb{Q}$_p) acts on the set of lattices by linear transformations: g · $\Lambda$ = g$\Lambda$. This action descends to an action of PGL(2, $\mathbb{Q}$_p) = GL(2, $\mathbb{Q}$_p) / $\mathbb{Q}$_p^$\times$ on T_p by tree automorphisms (isometries). The action extends continuously to the boundary, where it acts by the usual Möbius transformations:

```
( a  b )  ·  z  =  (az + b) / (cz + d)     for z ∈ ℚ_p ∪ {∞}
  ( c  d )
```

The stabilizer of a vertex is (a conjugate of) PGL(2, $\mathbb{Z}$_p), the maximal compact subgroup.

## 5. The Tree as a Discrete Symmetric Space

### 5.1 The Archimedean / Non-Archimedean Analogy

| Object | Archimedean (ℓ = $\infty$) | p-adic (ℓ = p) |
|--------|---------------------|-----------------|
| Field | $\mathbb{R}$ or $\mathbb{C}$ | $\mathbb{Q}$_p |
| Projective line | ℙ$^1 \mathbb{C}$) (Riemann sphere) | ℙ$^1 \mathbb{Q}$_p) (Cantor set) |
| Symmetric space | ℍ$^3$ (hyperbolic 3-space) or ℍ$^2$ | Bruhat–Tits tree T_p |
| Boundary | S$^2$ ≅ ℙ$^1 \mathbb{C}$) or S$^1$ ≅ ℙ$^1 \mathbb{R}$) | $\partial$T_p ≅ ℙ$^1 \mathbb{Q}$_p) |
| Isometry group | PSL(2, $\mathbb{C}$) or PSL(2, $\mathbb{R}$) | PGL(2, $\mathbb{Q}$_p) |
| Maximal compact | PSU(2) or PSO(2) | PGL(2, $\mathbb{Z}$_p) |
| Harmonic functions | Eigenfunctions of hyperbolic Laplacian $\Delta$_ℍ | Eigenfunctions of tree Laplacian $\Delta$_T |
| Spherical functions | Macdonald–Bessel functions (K_ir) | Macdonald spherical functions on T_p |

### 5.2 The Tree Laplacian

The **combinatorial Laplacian** on T_p acts on functions f: Vert(T_p) $\to \mathbb{C}$ by:

```
Δ_T f(v) = f(v) − (1/(p+1)) Σ_{v'∼v} f(v')
```

This is a bounded, self-adjoint operator on ℓ$^2$(Vert(T_p)). Its spectrum is continuous (for the full tree), and its eigenfunctions are the **spherical functions**.

### 5.3 Spherical Functions

Fix a base vertex v$_0$. A **spherical function** $\varphi$_s is a radial eigenfunction of $\Delta$_T:

```
Δ_T φ_s = (1 − λ_s) φ_s    where λ_s = (p^s + p^{1−s})/(p+1)
```

normalized so that $\varphi$_s(v$_0$) = 1. The explicit formula is:

```
φ_s(d) = p^{−sd} · (1 − p^{1−2s})/(1 − p^{1−2s})  +  (reflection term)
```

More elegantly, $\varphi$_s(d) is expressed in terms of the **Macdonald c-function**:

```
c(s) = (1 − p^{s−1}) / (1 − p^{-s})
```

The spherical Fourier transform (Satake transform) maps functions on the tree to functions on the parameter s ∈ i$\mathbb{R}$ ∪ [0,1], establishing a **Plancherel formula** for the tree.

## 6. Applications to Modular Forms

### 6.1 p-adic Modular Forms

Classical modular forms (over $\mathbb{Q}$) can be studied p-adically by considering their q-expansions modulo p^k and passing to limits. A **p-adic modular form** is a p-adic limit of classical modular forms.

### 6.2 The Tree and Modular Curves

The quotient of T_p by a discrete subgroup $\Gamma$ ⊂ PGL(2, $\mathbb{Q}$_p) produces a finite graph (or a graph with cusps). For $\Gamma$ = PGL(2, $\mathbb{Z}$[1/p]), the quotient is related to the **modular curve** X$_0$(p), and harmonic functions on this quotient correspond to **p-adic automorphic forms**.

### 6.3 Serre's Work

In his monograph *Trees* (1980), Serre showed that the theory of discrete subgroups of PGL(2, $\mathbb{Q}$_p) acting on the tree is in exact analogy with the theory of Fuchsian groups acting on the upper half-plane. The tree T_p is, in Serre's words, "a p-adic, combinatorial version of the Poincaré half-plane" [1].

## 7. Higher-Rank Buildings

### 7.1 Bruhat–Tits Buildings for General Groups

For a general reductive group G over $\mathbb{Q}$_p (not just SL(2) or GL(2)), the **Bruhat–Tits building** B(G, $\mathbb{Q}$_p) is a polysimplicial complex that generalizes the tree T_p. Key properties:

- B(G, $\mathbb{Q}$_p) is contractible.
- G($\mathbb{Q}$_p) acts by isometries with compact stabilizers.
- The dimension equals the split rank of G over $\mathbb{Q}$_p.
- The **apartments** are affine spaces (Euclidean tilings) for the maximal split torus.

For SL(n, $\mathbb{Q}$_p), the building has dimension n−1. The vertices correspond to homothety classes of $\mathbb{Z}$_p-lattices in $\mathbb{Q}$_p^n, with adjacency relations given by inclusions as for n = 2.

### 7.2 Relevance to p-adic Langlands

The Langlands program for a p-adic group G($\mathbb{Q}$_p) involves harmonic analysis on the Bruhat–Tits building B(G, $\mathbb{Q}$_p). The representation theory of G($\mathbb{Q}$_p) (smooth, admissible representations) is related to the geometry of the building, with:

- **Spherical representations** ↔ functions on the building invariant under a hyperspecial maximal compact.
- **Iwahori–spherical representations** ↔ functions on the chambers (alcoves) of the building.
- The **Satake isomorphism** lifts spherical functions to the Langlands dual group.

## 8. The p-adic Langlands Correspondence

### 8.1 Local Langlands

The **local Langlands correspondence** for GL(n) over a p-adic field (proved by Harris–Taylor, Henniart) establishes a bijection:

```
{ irreducible smooth representations of GL(n, ℚ_p) }
    ↕
{ n-dimensional Frobenius-semisimple Weil–Deligne representations of W_{ℚ_p} }
```

This generalizes local class field theory (n = 1).

### 8.2 p-adic Local Langlands

The **p-adic local Langlands correspondence** for GL(2, $\mathbb{Q}$_p), developed by Colmez, Dospinescu, Paskunas, and others, concerns p-adic Banach space representations (rather than smooth representations over $\mathbb{C}$). It relates:

```
{ unitary p-adic Banach representations of GL(2, ℚ_p) }
    ↕
{ 2-dimensional continuous representations of Gal(ℚ̄_p/ℚ_p) over p-adic fields }
```

This is much more delicate than the classical local Langlands correspondence because p-adic representations are not semisimple in general.

### 8.3 Geometrization

Fargues and Scholze [2] have proposed a **geometrization** of the local Langlands correspondence using the **Fargues–Fontaine curve** — a "p-adic Riemann surface" whose geometry encodes p-adic Hodge theory. In their framework:

```
D-mod(Bun_G)  ≅  QCoh(Stack of L-parameters)
```

where Bun_G is the stack of G-bundles on the Fargues–Fontaine curve. This is a p-adic analog of the geometric Langlands correspondence, and it is deeply inspired by the Kapustin–Witten picture.

---

## 9. Connecting Back to Kapustin–Witten

The full circle of ideas is:

```
  Archimedean (ℓ = ∞)                    Non-Archimedean (ℓ = p)
  ─────────────────────                  ─────────────────────────
  Riemann surface C                       p-adic curve (Fargues–Fontaine)
  Hitchin moduli space M_H(C)             Moduli of G-bundles on FF curve
  S-duality in N = 4 SYM                  ? (p-adic gauge theory)
  Geometric Langlands (proved 2024)       Geometrized local Langlands (Fargues–Scholze)
```

The **open question** is: can one construct a fully physical "p-adic gauge theory" on the Bruhat–Tits building (or the Fargues–Fontaine curve) whose dualities reproduce the p-adic Langlands correspondence? This would complete the physical derivation of the Langlands program for **all** completions of $\mathbb{Q}$, not just the Archimedean one.
