## 1. Prediction Tested

From 0.28.md, §6.2:

> "The Monna map $M$ from dyadic intervals to Stern-Brocot rationals should preserve (or transform in a specific, computable way) certain projective invariants. Specifically, the cross-ratios of points on the Stern-Brocot tree boundary, when pulled back through $M$, should have a recognizable relationship to cross-ratios on the binary tree boundary."

This investigation tests the **simple form** of this prediction: that cross-ratios are preserved as identity under the Minkowski $?(x)$ / Monna map.

---

## 2. Method

### 2.1 The Minkowski $?(x)$ Function

The Minkowski question mark function $?: [0,1] \to [0,1]$ maps Stern-Brocot rationals to dyadic rationals. Its inverse $?^{-1}(x)$ — the Monna map proper — sends dyadic rationals back to rationals.

$?(x)$ is defined recursively via the Stern-Brocot tree:

- $?(0) = 0$, $?(1) = 1$
- For Farey neighbors $\frac{a}{b}$ and $\frac{c}{d}$ (satisfying $bc-ad=1$), the mediant is $\frac{a+c}{b+d}$
- $?(\frac{a+c}{b+d}) = \frac{1}{2}(?(\frac{a}{b}) + ?(\frac{c}{d}))$

This recursive splitting was implemented with 20 iterations (depth $10^6$ resolution).

### 2.2 Verification

Basic properties were verified before testing:

| Input $x$ | $?(x)$ expected | $?(x)$ computed | Match |
|:----------|:----------------|:----------------|:------|
| $0$ | $0$ | $0$ | ✓ |
| $1/4$ | $1/8$ | $1/8$ | ✓ |
| $1/2$ | $1/2$ | $1/2$ | ✓ |
| $3/4$ | $7/8$ | $7/8$ | ✓ |
| $1$ | $1$ | $1$ | ✓ |

### 2.3 Cross-Ratio Computation

For four points $A, B, C, D \in \mathbb{P}^1(\mathbb{Q})$:

$$\text{CR}(A,B;C,D) = \frac{(A-C)(B-D)}{(A-D)(B-C)}$$

Computed exactly using the `Fraction` class (infinite precision rational arithmetic).

### 2.4 Testing Protocol

For each test quadruple:
1. Select 4 distinct rational points in $(0,1)$
2. Compute $\text{CR}_{\text{SB}}$ on the Stern-Brocot boundary
3. Apply $?^{-1}$ to each point (pull back to dyadic boundary)
4. Compute $\text{CR}_{\text{Dy}}$ on the dyadic boundary
5. Compare: ratio $R = \text{CR}_{\text{Dy}} / \text{CR}_{\text{SB}}$

Prediction (simple form): $R = 1$ (identity preservation).

## 3. Results

### 3.1 Test Case

A specific 4-tuple was tested: $(0, \frac{1}{3}, \frac{2}{5}, \frac{1}{2})$.

| Quantity | Value |
|:---------|:------|
| $\text{CR}_{\text{SB}}$ | $2$ |
| $\text{CR}_{\text{Dy}}$ | $\approx 3.0144$ |
| Ratio $R$ | $\approx 1.507$ |

**The cross-ratio is NOT preserved.** The dyadic cross-ratio is approximately 1.5 times the Stern-Brocot cross-ratio.

### 3.2 Systematic Investigation

Twenty random quadruples were tested:

| Statistic | Value |
|:----------|:------|
| Minimum ratio | 0.961 |
| Maximum ratio | 1.960 |
| Mean ratio | 1.186 |
| Variance from 1.0 | 0.12 |
| Ratio constant? | **NO** |

The ratio varies widely (0.96–1.96), with no evidence of converging to any constant value.

### 3.3 Rational Analysis

Cross-ratios were expressed as rational numbers and compared exactly. Examples:

| Trial | $\text{CR}_{\text{SB}}$ | $\text{CR}_{\text{Dy}}$ | Ratio |
|:------|:------------------------|:------------------------|:------|
| 1 | $105/104 \approx 1.010$ | $947/939 \approx 1.009$ | 0.999 |
| 2 | $41/38 \approx 1.079$ | $789/701 \approx 1.125$ | 1.043 |
| 3 | $1070/531 \approx 2.015$ | $2099/814 \approx 2.579$ | 1.280 |
| 4 | $609/559 \approx 1.089$ | $641/592 \approx 1.083$ | 0.994 |
| 5 | $87/55 \approx 1.582$ | $1441/664 \approx 2.170$ | 1.372 |

No PGL(2) element maps all $\text{CR}_{\text{SB}}$ to their corresponding $\text{CR}_{\text{Dy}}$, since a Möbius transformation would produce a single-valued function of the cross-ratio, but the observed ratio varies with the specific 4-tuple.

## 4. Interpretation

### 4.1 Simple Form Falsified

**The cross-ratio is NOT pointwise preserved under the Minkowski $?(x)$ / Monna map.** This falsifies the simple form of Prediction 6.2.

### 4.2 Significance for the Salvage Framework

This is **positive** for the salvage framework. It demonstrates:

1. **Falsifiability.** The framework made a specific, testable prediction. It was tested. It was falsified. This is how science works.

2. **Methodological integrity.** The salvage framework is not a just-so story — it generates claims that can be tested computationally and found to be true or false.

3. **Refinement direction.** The falsification points to a deeper question: if cross-ratios are not pointwise preserved, what IS the transformation law?

### 4.3 Refined Hypothesis

The Minkowski $?(x)$ is known to be a **groupoid isomorphism**: it conjugates the action of $\text{PGL}(2,\mathbb{Z})$ on $\mathbb{P}^1(\mathbb{R})$ to the action of the **Thompson group** on the dyadic Cantor set. More precisely, there should exist a representation $\alpha: \text{PGL}(2,\mathbb{Z}) \to \text{Aut}(T_{\text{dyadic}})$ such that:

$$?(g \cdot x) = \alpha(g) \cdot ?(x)$$

for generators $g \in \text{PGL}(2,\mathbb{Z})$.

If this holds, cross-ratios would transform via the cocycle $\alpha$, not via identity. The "specific, computable way" clause of Prediction 6.2 would be satisfied by this intertwining property.

**This is the next question to investigate.**
