# Ultrametric Quantum Computation

**An MVP Program for Passive Geometric Fault Tolerance**

Foundational research on ultrametric quantum computing architectures using
Bruhat-Tits tree geometry for passive error suppression. This repository
precedes and informs the [QWAV](https://github.com/QNFO/QWAV) initiative.
